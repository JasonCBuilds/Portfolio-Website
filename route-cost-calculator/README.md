# Last-Mile Delivery Cost Calculator

Interactive route-economics tool in the JasonCBuilds Operations Toolkit.

## What it demonstrates

- Transportation cost modeling
- Fuel and labor cost analysis
- Cost-per-stop calculations
- Margin-based route pricing
- Operational scenario planning

## Live portfolio path

`/route-cost-calculator/`

The tool is built with HTML, CSS, and vanilla JavaScript and requires no build step.
